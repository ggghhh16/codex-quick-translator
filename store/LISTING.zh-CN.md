# Chrome 网上应用店提交文案

名称：快速翻译 · Local Codex

简短介绍：划词快速翻译为所选语言，结合网页语境解释表达，支持带来源的 Markdown 收藏。需要 Windows 本地 Codex。

类别建议：工具；语言：简体中文。

## 详细介绍

在网页上选择文字，右键点击“快速翻译”，即可在原文旁查看所选语言的翻译、表达解释和网页语境。也支持 Alt+Shift+T 快捷键。

使用前提：目前支持 Windows。需要安装并登录 Codex、Node.js 20+，并另外安装本项目的开源本地连接程序。只安装浏览器扩展不能完成翻译；本地安装步骤可在扩展设置页查看。模型推理通过你的 Codex 账号及其配置的云端服务进行，可能消耗模型服务额度；此扩展不提供免费模型额度。

主要功能：
• 深色圆角悬浮窗，支持拖动和四角缩放。
• 目标语言可在设置中修改，翻译、解释与语境均使用所选语言。提供 150 多种语言选项及自定义语言代码，实际支持和质量取决于模型。
• 浮窗界面跟随所选目标语言，保存后立即更新；工具栏设置页和右键菜单跟随 Chrome。界面提供简繁中文、英、西、法、德、日、韩、阿拉伯语和巴西葡萄牙语；其他界面语言回退英文。新安装默认目标语言跟随浏览器，旧用户保留中文直到主动更改。
• 模型、思考强度和快速服务独立设置；默认 GPT-6 Luna、low 和标称 1.5× 快速服务。可用模型、倍率与额度由 Codex 账号和服务决定，实际速度不作保证。
• 点击旗帜，将原文、翻译、解释、语境、来源网页与可点击网址追加到指定的本地 Markdown 文件。
• 支持停止、重试、复制和 Esc 关闭。

仅在你主动触发翻译时读取选区、附近段落和有限页面正文。不持续追踪浏览历史，不读取 Cookie，不设置广告或统计服务。材料会发送给你在 Codex 中配置的模型服务，不是离线翻译。详情请阅读隐私政策。

Chrome 内置页面、扩展商店、内置 PDF 阅读器及部分跨域嵌入页面不支持翻译浮窗。较长或动态加载的页面只能提供已经呈现的有限正文上下文。来源链接经过隐私处理，依赖特殊查询参数的网页可能无法直接定位。

独立开源项目，与 OpenAI 或 Google 无官方隶属关系。

## 单一用途

在用户主动划词时，将选中文字结合当前网页的有限上下文翻译为所选语言，并允许用户将同一翻译结果连同来源收藏到本地 Markdown。

## 权限理由

- activeTab：仅在用户点击右键翻译或使用快捷键后，临时访问当前页面的选区和上下文。
- scripting：按需注入本地打包的翻译浮窗与设置代码；不常驻注入所有网站。
- contextMenus：为选中文字提供“快速翻译”右键入口。
- nativeMessaging：连接必须安装的本机开源程序，使用已登录的 Codex App Server 完成翻译，以及按用户主动点击将结果追加到指定 Markdown 文件。

## 隐私表单依据

需要声明处理“网站内容”和“网络记录/浏览活动中的页面 URL”。不勾选“完全不处理用户数据”：即使经本机连接程序发送，页面材料仍会交给云端模型服务。材料可能包含用户所阅读的个人信息；如果后台要求按内容进一步分类，应据其定义如实填报。

不出售数据、不用于与单一用途无关的目的、不用于信用判断；无广告、分析或开发者数据服务器。无远程托管的扩展可执行代码。独立安装的开源 Native Messaging 连接程序及 Codex 是已披露的依赖，源代码公开可检查；模型输出以纯文本呈现，不作为代码执行。
